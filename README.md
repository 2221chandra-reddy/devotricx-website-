# DevotricX Technologies Website

Premium corporate website for **DevotricX Technologies Private Limited**.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Features

- Dark theme (`#0B1020`) with red accent (`#E10600`)
- Light/dark mode toggle
- Particle hero background + mouse-follow glow
- Glassmorphism service & portfolio sections
- Animated counters, process timeline, testimonials carousel
- Tech & client marquees
- Contact form UI + WhatsApp / AI assistant widgets

## Customize

Update contact details in `src/components/Contact.tsx` and `src/components/Footer.tsx`.
Replace placeholder map, phone, email, and WhatsApp numbers with your real company info.
